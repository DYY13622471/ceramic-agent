# examples

本目录只放**本项目自己生成的成品**，不放任何第三方内容。

- `auto_bowl_view.png` / `auto_bottle2_view.png` / `auto_cup_view.png`：智能体生成的碗、瓶、杯的视口截图，用来展示输出长什么样。
- `sample_scripts/`：`generated/` 里的真实产出脚本样例，可以直接拖进 Rhino 的 ScriptEditor 运行。

如果想补充自己的案例截图，请新建 `examples/local/` 并加进 `.gitignore`，不要直接放在这里——
案例截图里可能含客户器型，不适合随仓库分发。
